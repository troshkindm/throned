# Releasing Throned

A release is a tag push. Nothing else publishes anything.

## The tag

`.github/workflows/throned-windows.yml` triggers on tags matching
`[0-9]*.[0-9]*.[0-9]*` — bare `1.2.3`, no `v` prefix. The tag name becomes the
version the application shows and the name of every artifact, so it must be
right before it is pushed.

Pushing a tag runs the full matrix: both architectures, both the bundled-Qt and
system-Qt Linux variants, DEB and RPM packages, the Windows installer, and the
GitHub release itself. A push to `dev` runs a narrower matrix and publishes
nothing.

## Before tagging

- `ctest` and `./script/ui_snapshot.sh` are green on `dev`.
- The version in the tag has not been used.
- Release notes are written (below). The release body cannot be regenerated by
  the workflow afterwards; it is edited on the release page.

## Localized release notes

GitHub keeps one release body, and the in-app updater shows only the section
matching the interface language. Sections are delimited by invisible HTML
comments. English comes first; other languages go inside ordinary `<details>`
blocks so the GitHub page stays readable.

```md
<!-- throned:lang=en -->
## What's new

- ...
<!-- throned:lang=end -->

<details>
<summary>Русский</summary>

<!-- throned:lang=ru -->
## Что нового

- ...
<!-- throned:lang=end -->

</details>
```

A regional locale such as `ru_RU` resolves `ru-ru`, then `ru`, then English,
then the first translated block. A body with no markers is shown unchanged, so
old releases stay compatible, and a malformed marked body is left intact rather
than hiding text. `docs/release-notes.md` is the reference.

Check both languages against the real dialog before publishing:

```powershell
Throned.exe --update-prompt-preview --notes release.md -lang en --output update-en.png
Throned.exe --update-prompt-preview --notes release.md -lang ru --output update-ru.png
```

## Do not

Tag or push on someone's behalf without being asked. A tag is public the moment
it is pushed and the workflow publishes from it immediately.
