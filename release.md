## What's new

- Improved compact mode: the window keeps its size when restored from the tray, and routing controls fit the default width.
- Fixed the server list jumping back while scrolling during background updates.
- Redesigned speed and latency test progress with a progress bar, completed-server count, live transfer speeds, and a stop button in both window modes. Fixed missing progress when starting tests from keyboard shortcuts or context menus.
- Routing drafts now survive profile switches and background updates. Applying rules preserves selected servers, blocked targets, full application paths, and advanced rules from the full editor.
- Subscription previews no longer steal focus on hover.
- Fixed the duplicate, unnamed page in routing settings, labeled the default domain strategies, and improved spacing in compact routing entries.
- Removed the Mica promotional notice.
- Removed extra separator lines above subscription tabs on Linux and updated the log filter button to match the other controls.
- Merged upstream improvements, including saved server sorting, local QUIC signature generation for AmneziaWG, DNS fixes for tests on Linux with TUN enabled, and network dependency updates.

## Что нового

- Доработан компактный режим: окно сохраняет размеры после восстановления из трея, а элементы маршрутизации помещаются при стандартной ширине.
- Исправлены скачки списка серверов при прокрутке во время фоновых обновлений.
- Обновлён прогресс проверки скорости и задержки: полоса выполнения, счётчик серверов, текущие скорости и кнопка остановки в обоих режимах окна. Исправлено отсутствие прогресса при запуске через горячие клавиши или контекстное меню.
- Черновики маршрутов сохраняются при переключении профилей и фоновых обновлениях. Применение правил сохраняет выбранные серверы, блокировку, полные пути приложений и расширенные правила из полного редактора.
- Карточка подписки больше не перехватывает фокус при наведении.
- Исправлена дублирующаяся вкладка без названия в настройках маршрутизации. Добавлены подписи стратегий по умолчанию и отступы в плашках компактных маршрутов.
- Убрано уведомление с предложением попробовать Mica.
- Убраны лишние линии над вкладками подписок в Linux. Кнопка фильтра логов приведена к общему стилю элементов управления.
- Подтянуты улучшения из upstream: сохраняемая сортировка серверов, локальная генерация сигнатур QUIC для AmneziaWG, исправления DNS при тестировании в Linux с включённым TUN и обновления сетевых зависимостей.
